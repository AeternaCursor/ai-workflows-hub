# 通用模板合集

按规模排序的现成工作流模板库，**导入即用**。

## n8n 生态（数量最大）

- [n8n 官方模板库](https://n8n.io/workflows) — 数千个官方 + 社区模板，按类别/集成筛选，编辑器内可直接浏览
- [GitHub 上的 n8n 模板合集搜索](https://github.com/search?q=awesome-n8n-templates&type=repositories&s=stars&o=desc) — 按星排序浏览：
  - **awesome-n8n-templates** — 280+ 免费模板（Gmail / Telegram / Slack / Discord / WhatsApp / Notion / OpenAI）
  - **8,697+ 大合集** — 最大开源集合：25 个类别、236 个集成、含向量库 / embedding / LLM 流水线
  - 200+ 开箱即用自动化、AI Agency 起步模板等多个社区合集

> 提示：n8n 模板为 JSON 文件，导入路径：编辑器 → Workflows → Import from File

## ComfyUI 生态（图像 / 视频）

- [comfy-org/workflow_templates](https://github.com/comfy-org/workflow_templates) — 官方工作流模板 + 可复用子图（subgraph blueprints）
- [ComfyUI 官方工作流画廊](https://comfy.org/workflows) — 按文生图 / 图生视频 / 数字人口播分类浏览，一键复制
- [ComfyUI 官方文档示例](https://docs.comfy.org/zh/tutorials/video/wan/wan2_2) — Wan2.1/2.2 文生视频、图生视频、首尾帧原生工作流

## Dify 生态（LLM 应用）

- [Dify Marketplace](https://marketplace.dify.ai/templates) — 官方模板市场：SEO Agent、采购 Copilot、多步 RAG 管线（问题抽取 → 循环检索 → 引用生成）
- 支持一键采用（one-click adopt），也可导出 DSL YAML 收录进本仓库

## Coze 生态

- [coze-dev/coze-studio](https://github.com/coze-dev/coze-studio) — 开源版扣子，自带插件定义/调用/管理体系
- 字节开源前端流程引擎 [FlowGram](https://github.com/bytedance/flowgram.ai)（Coze 工作流底层）

## GitHub 官方

- [github/gh-aw](https://github.com/github/gh-aw) — GitHub Agentic Workflows：用 Markdown 定义 AI 工作流，跑在 Actions 里，MIT 协议
- 示例仓库：githubnext/agentics — issue 分诊、PR 审查、自动修 bug
