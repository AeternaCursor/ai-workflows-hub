# 用 AI 定制/迭代工作流（通用总纲）

> 想把仓库里的工作流改成自己的业务版？不用自己学节点编程——
> 把下面的提示词骨架 + 目标工作流的 README/TUTORIAL/workflow.json 一起发给任意 AI 助手
> （Claude / Codex / Cursor / Trae 均可），它来改，你验收。

## 通用提示词骨架（复制后填空）

```
你是 n8n/ComfyUI 工作流工程师。我有一个现成的工作流（JSON 和文档附后），帮我改造。

【现状】它目前做：{{一句话，从工作流 README 复制}}
【目标】我想让它：{{你的具体需求，例：摘要结果推送到飞书而不是 Gmail}}

【硬性要求】
1. 只改需要改的节点，其余保持原样；输出修改前后的节点对比说明
2. 直接给我改好的完整 workflow.json（可导入 n8n）
3. 新增凭据/账号需要什么，列一张清单告诉我去哪申请
4. 如果我的需求当前节点体系做不到，明确说不，并给出最小改造路径
5. 改完后给我 3 步验收方法

【我的环境】{{例：Windows / n8n 1.x 自托管 / 已有 OpenAI Key}}
```

## 常见迭代方向的现成指令

| 想改什么 | 直接说（附在【目标】里） |
|---|---|
| 换通知渠道 | "把 X 节点换成飞书/钉钉/企业微信机器人节点，webhook 地址我用占位符" |
| 换模型降成本 | "把 OpenAI 换成 DeepSeek(gpt-4o→deepseek-chat)，保持输出格式不变" |
| 加过滤条件 | "在 X 节点后加 IF：只处理{{条件}}，其余直接结束" |
| 加人工确认 | "在执行 X 之前暂停等待审批，用 n8n 的 Wait/Human in the loop 节点" |
| 定时批处理 | "改成每天 9 点跑一次，数据源改为 Google Sheets 的第 X 个工作表" |
| 中文化输出 | "所有 AI 节点的提示词改为中文输出，格式要求写死在 prompt 里" |

## 验收三步法（AI 改完必做）

1. **导入不报错**：n8n → Import from File，画布节点无红色感叹号
2. **测试数据跑通**：用最小输入跑一次 Test workflow，全绿
3. **输出符合预期**：结果格式/渠道/语言都对，再开 Active

## 安全红线

- ❌ 不要把带真实 API Key 的 JSON 发给 AI——发之前把 `credentials` 段删掉
- ❌ 不要让 AI"顺手优化"没让你改的部分
- ✅ 改完的 JSON 先在测试环境跑，再接管生产触发器
