# AI 发展史时间线

动画时间线页面，数据与展示完全分离 —— **新增事件只需编辑 [data.js](data.js)**。

## 本地预览

双击打开 `index.html` 即可（无需服务器，数据以内联脚本加载）。

## 添加事件

在 `data.js` 的 `TIMELINE_DATA` 数组中按日期顺序（或任意顺序，页面会自动排序）追加：

```js
{ year: "2026", date: "2026-11", title: "事件标题", cat: "agent",
  desc: "一两句话说清楚这件事为什么重要。",
  link: "https://..." }   // link 可选
```

`cat` 分类与颜色（定义在 `CATEGORIES` 中）：

| 值 | 含义 |
|---|---|
| `foundation` | 基础奠基（早期理论、里程碑突破） |
| `model` | 模型里程碑（新模型发布、能力跃迁） |
| `tools` | 工具与平台（开发者工具、编辑器） |
| `agent` | Agent 与工作流（Agent 框架、协议、行业工作流） |
| `opensource` | 开源生态（重要开源发布、社区事件） |
| `multimodal` | 多模态生成（文生图/视频/语音） |

## 收录标准

- 对 AI 走向有实质影响的事件（技术、产品、开源、生态）
- 一条只记一件事，描述控制在 60 字内
- 附可靠来源链接（官方公告 / 论文 / 仓库）

## 使用 AI 自动追加

把 [prompts/update-hub.md](../prompts/update-hub.md) 喂给任意 AI 助手，其中包含
「新增时间线事件」的完整规范。
