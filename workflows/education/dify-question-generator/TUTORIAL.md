# 实操教程：Dify 智能出卷

> 全程约 20 分钟（Dify 已装好为前提，安装见
> [Quickstart 路线三](../../../docs/quickstart.md)）。

## 前置清单

- Dify 可访问（自托管 `http://localhost` 或云版）
- 已在"设置 → 模型供应商"配置好至少一个对话模型（OpenAI / DeepSeek / 通义 / Bedrock 均可）

## 导入与换模型

1. Dify 工作室 → 创建空白应用 → 旁边菜单选 **导入 DSL** → 上传本目录 `workflow.yml`
2. 画布上两个 **LLM 节点**（"LLM" 与 "LLM 2"）默认是
   `anthropic.claude-3-5-sonnet-20241022-v2:0`（Bedrock）：
   点开节点 → 模型下拉 → **换成你配置好的模型**即可，提示词不用动
3. 右上角"发布"可选发布为 Web 应用，发给不会用 Dify 的老师直接填表

## 流程与节点说明（9 节点）

```
开始（8 个表单项）
  → 代码执行 2（判断 reference 是 URL 还是文本）
  → 条件分支（是 URL？）
       ├─ 是 → 网页爬虫（Dify 内置工具，抓取教材网页）
       └─ 否 → （直接透传文本）
  → 变量聚合器（统一两路输出）
  → LLM（按表单要求出题，答案用标记语法内嵌）
  → LLM 2（以"审卷老师"身份校对：查错、修格式，<thinking>思考/<answer>成卷）
  → 代码执行（正则提取 <answer> 内的最终试卷）
  → 结束（输出 body）
```

- **开始节点表单项**：`grade` 年级、`subject` 科目、`types` 题型、`count` 数量、
  `difficulty` 难度（必填）；`reference` 参考资料、`topics` 主题、`comments` 备注（可选）
- **答案标记**：单选 `- (x)`、多选 `- [x]`、填空 `- R:=答案`——后续可用脚本自动阅卷

## 跑第一次

| 表单项 | 示例值 |
|---|---|
| reference | `https://zh.wikipedia.org/wiki/光合作用`（或粘贴一段课文） |
| grade | 初二 |
| subject | 生物 |
| types | 单选题、填空题 |
| count | 6 |
| difficulty | 中等 |

运行 → 结束节点输出 Markdown 试卷。检查题目是否真的围绕参考资料出题
（这是判断"网页爬虫→出题"链路是否正常的关键）。

## 常见报错

| 报错 | 解法 |
|---|---|
| 导入 DSL 失败 | Dify 版本过旧，升级到 0.6+ 再导 |
| LLM 节点红点/报模型错误 | 模型没配置或额度不足：设置 → 模型供应商里检查 |
| 网页爬虫抓不到内容 | 目标站点反爬；改用"粘贴文本"方式传参考资料 |
| 输出没走 <answer> 提取 | 第二个 LLM 输出异常，重跑一次；模型较弱时可把 LLM 2 换更强模型 |
