# 光合作用随堂测验（初二生物）

---

1. 光合作用主要发生在植物细胞的哪种结构中？
    - ( ) 线粒体
    - (x) 叶绿体
    - ( ) 细胞核
    - ( ) 液泡

2. 光合作用所需的原料不包括下列哪一项？
    - ( ) 二氧化碳
    - ( ) 水
    - (x) 葡萄糖
    - ( ) 光能

3. 暗处理（遮光处理）叶片的实验目的是？
    - (x) 耗尽叶片中原有的淀粉
    - ( ) 增加叶片中的叶绿素
    - ( ) 提高光合作用速率
    - ( ) 使叶片变软便于染色

4. 银边天竺葵的银边部分滴加碘液不变蓝，说明光合作用需要？
    - (x) 叶绿体（叶绿素）
    - ( ) 二氧化碳
    - ( ) 适宜的温度
    - ( ) 水

5. 光合作用吸收的气体是____，释放的气体是____。
    - R:=二氧化碳；氧气

6. 绿色植物通过光合作用把光能转化为____能，储存在有机物（如____）中。
    - R:=化学；淀粉（或葡萄糖）
