# 通用办公 AI 工作流 🗂️

不限定行业、人人可用的提效工作流。

## 精选参考

| 工作流 | 平台 | 说明 |
|---|---|---|
| 📦 [邮件摘要 Agent](email-summary/)（已收录） | n8n | 新邮件自动中文摘要+重要度分级，42k 人气入门模板 |
| 邮件自动处理 | n8n | [官方库](https://n8n.io/workflows) 搜索 `email`：分类、摘要、草稿回复 |
| 会议纪要 | n8n / Dify | 录音转写 → 要点提取 → 待办分发 |
| 文档问答 | Dify | [Marketplace](https://marketplace.dify.ai/templates)：文档入库 → RAG 问答 |
| 数据报表 | n8n | 定时拉取多源数据 → 汇总 → 图表推送 |

## 典型场景

- 邮件 / 消息智能分类与摘要
- 会议录音 → 纪要 → 待办 → 分发
- 周报 / 月报自动汇总
- 多平台文件自动归档同步

## 平台模板入口

- [awesome-n8n-templates 合集搜索](https://github.com/search?q=awesome-n8n-templates&type=repositories&s=stars&o=desc) — Gmail / Slack / Notion / Google Drive 集成最全
