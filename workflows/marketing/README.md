# 营销 AI 工作流 📣

## 精选参考

| 工作流 | 平台 | 说明 |
|---|---|---|
| [SalesGPT](https://github.com/filip-michalsky/SalesGPT) | LangChain | 对话式销售 Agent，可配置销售阶段 + 异议处理 |
| SEO Agent | Dify | [Marketplace](https://marketplace.dify.ai/templates) 热门模板，关键词 → 内容 → 优化建议 |
| 内容多渠道分发 | n8n | [官方库](https://n8n.io/workflows) 搜索 `social media`，一稿多发到多平台 |

## 典型场景

- 选题 → 初稿 → 配图 → 多平台发布的内容流水线
- SEO 关键词研究与优化
- 线索评分与销售跟进自动化
- 邮件营销个性化文案

## 平台模板入口

- [n8n 官方库](https://n8n.io/workflows) 搜索：`marketing`、`seo`、`newsletter`
- [Dify Marketplace](https://marketplace.dify.ai/templates) 搜索：`SEO`、`content`
- [ComfyUI 画廊](https://comfy.org/workflows)：营销视觉素材生成
