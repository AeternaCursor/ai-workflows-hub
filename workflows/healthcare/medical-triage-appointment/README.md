# AI 预检分诊与预约自动化

> 来源：[n8n 官方模板 #9446](https://n8n.io/workflows/9446) · 22 节点
> 📖 手把手实操：[TUTORIAL.md](TUTORIAL.md)
> 🧪 实操案例与代码：[CASES.md](CASES.md)

患者填表（Jotform）→ GPT-4 按症状做紧急度分级 → 急症立即邮件提醒、常规自动写日历排期 + 邮件确认。

- **平台**：n8n 1.x
- **所需凭据**：Jotform、OpenAI API Key、Gmail、Google Calendar
- **触发方式**：Jotform 表单提交
- **输入**：症状自述 + 期望时间
- **输出**：紧急度分级 + 日历预约 + 确认邮件

## ⚠️ 合规红线

AI 分诊仅做**流程优先级排序**，不输出诊断意见；涉及生命危险症状一律直接标"立即就医"。本工作流自托管运行，表单数据加密存储，遵守当地医疗数据法规。
