# 合同风险分析与合规审查

> 来源：[n8n 官方模板 #10761](https://n8n.io/workflows/10761) · 36 节点

> 📖 手把手实操：[TUTORIAL.md](TUTORIAL.md)

合同以邮件附件到达 → GPT-4.1 Mini 提取关键条款（甲乙方/金额/期限/违约责任）→
向量检索比对公司合规规则库 → 输出风险等级与整改建议 → 推送 Slack 提醒律师复核。

- **平台**：n8n 1.x
- **所需凭据**：Gmail（触发）、OpenAI API Key（含 embeddings）、Slack
- **触发方式**：Gmail 新邮件（含合同附件）
- **输入**：合同 PDF/DOCX
- **输出**：结构化条款表 + 风险分析报告 + Slack 预警

## 使用步骤

1. 导入 `workflow.json`
2. 配置 Gmail、OpenAI、Slack 凭据
3. 建立合规规则知识库（向量库入库节点）
4. 用标准合同样例试跑，校准风险阈值

## 重要说明

本目录填补了仓库此前认定的"法务开源空白区"。所有输出为**律师复核参考**，
不构成法律意见；合同属商业敏感文件，建议自托管 n8n 并控制访问范围。
