# 电商 AI 工作流 🛒

## 精选参考

| 工作流 | 平台 | 说明 |
|---|---|---|
| 📦 [Shopify 订单自动履约](shopify-order/)（已收录） | n8n | 新订单 → 核对 → 通知仓储物流 → 状态回写 |
| [Commerce Agents 目录](https://dingminghbut.github.io/Awesome-AI-GitHub/agents.html) | 多平台 | 96 个电商运营 Agent 项目追踪（Listing / 定价 / 广告 / CRM / 订单 / SOP） |
| 商品 Listing 生成 | Dify / Coze | 关键词 → 标题 + 五点描述 + 详情页文案 |
| 客服工单路由 | n8n | 退款 / 物流 / 咨询自动分类分派 |

## 典型场景

- 商品 Listing 多语言生成与优化
- 差评监控 → 预警 → 回复建议
- 库存与价格监控告警
- 订单异常自动处理
